# AI-Based Employee & Workforce Intelligence System
**Using Machine Learning for Smart HR Decision-Making**
BCA (AI & DS) · Project Based Learning · Graphic Era Hill University, Haldwani
Team: Anusharan Singh · Arshdeep Kaur · Ishita Mehta  |  Guide: Ms. Vaishali Gupta

A full-stack ML project that turns raw employee data into predictive, explainable HR insights.

## Features (as per the project presentation)
| Feature | How it is built |
|---|---|
| Attrition prediction | Random Forest classifier |
| Performance prediction | Random Forest regressor (score 1-5) |
| Promotion prediction | Random Forest classifier |
| Training-need prediction | Random Forest classifier |
| Risk score (0-100) + level | Composite of attrition probability, performance gap, absenteeism and anomaly score; Low / Medium / High bands |
| Employee grouping | K-Means (k=4) → *Rising Stars, Established Core, Burnout Risk, Disengaged* |
| Anomaly detection | Isolation Forest, with a plain-English reason for each flagged employee |
| AI explanation | Model-agnostic occlusion: shows which factors push a prediction up or down for one employee |
| Employee intelligence / AI report | Search any employee → full report: predictions, drivers, recommendations |
| AI workforce report | Auto-generated findings and recommended actions for HR |
| What-if predictor | Score a new / hypothetical employee from a form |

## Tech stack
Python · Pandas · NumPy · Scikit-learn · Matplotlib · Seaborn · Flask (REST API) · HTML/CSS/JavaScript + Chart.js (bundled locally, works offline) · Jupyter Notebook · CSV dataset

## Quick start
```bash
python -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python run.py                      # first run trains the models (~30 s)
```
Open **http://127.0.0.1:5000**.

Optional commands:
```bash

python -m ml.train                 # retrain models + metrics + figures
pytest -q                          # run the tests
jupyter notebook notebooks/Workforce_Intelligence.ipynb
```

## Methodology (matches slide 5)
1. **Data collection**: Employee HR dataset (CSV).
2. **Data cleaning**: duplicates removed, missing values imputed (median / mode), outliers clipped.
3. **Feature selection**: 24 employee attributes; permutation importance shows which matter.
4. **Model training**: Random Forest models, 80/20 split; production models refit on all data.
5. **Prediction**: dashboard values are *out-of-fold* (5-fold CV) so they are not inflated by memorisation.
6. **Segmentation**: K-Means on standardised engagement / tenure / performance features.
7. **AI report**: per-employee insights with explanations.
8. **HR decision support**: prioritised recommendations and a workforce-level report.

## Results (20 % hold-out test set)
| Model | Key metrics |
|---|---|
| Attrition | ROC-AUC ≈ 0.85, recall ≈ 0.71 |
| Performance | R² ≈ 0.66, MAE ≈ 0.28 points |
| Promotion | ROC-AUC ≈ 0.72 |
| Training need | ROC-AUC ≈ 0.77 |

Sanity check: in the **High** risk band ~47 % of employees actually left, versus ~10 % in the **Low** band.

## Using your own data
Replace `data/employee_hr_data.csv` with a file that has the same column names (see the header of the
included CSV), delete the `models/` folder contents and run `python -m ml.train`.

## Notes
* The bundled dataset is **synthetic** (generated by `data/generate_dataset.py`) with realistic relationships,
  so no real employee data is used. Metrics will differ on real HR data.
* The explanations show statistical associations learned by the model, not proven causes. Use the outputs as
  decision *support* for HR, not as the sole basis for decisions about people.
